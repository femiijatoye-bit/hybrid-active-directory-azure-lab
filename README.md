# Hybrid Active Directory + Microsoft Azure Lab

A hands-on lab focused on building and administering a small corporate-style Windows environment using Active Directory Domain Services and Microsoft Azure.

> **Status:** In Progress

## Project Objectives

This lab is being built to develop and demonstrate practical experience with:

- Windows Server administration
- Active Directory Domain Services (AD DS)
- Users, groups, and Organizational Units (OUs)
- Group Policy
- DNS and IP configuration
- Windows domain joining
- Microsoft Azure virtual networking
- Azure Network Security Groups (NSGs)
- Windows client administration
- Identity and access management
- Troubleshooting and validation
- Microsoft Entra ID / hybrid identity integration
